# Hello world

A small hello world in two languages I enjoy for different reasons: Clojure and Kotlin.

## Clojure

```clojure
(println "hello world")
```

Positive points:

- Small core, strong expressiveness, and a focus on simple data transformations.
- Excellent fit for interactive development through the REPL.
- Great for modeling evolving domains with immutable data and functional composition.

## Kotlin

```kotlin
fun main() {
    println("hello world")
}
```

Positive points:

- Clear, concise syntax with strong static typing.
- Smooth integration with the JVM ecosystem and existing Java libraries.
- Productive for building APIs and services with readable, maintainable code.

## OOP and functional programming

Object-oriented programming is useful when a system benefits from explicit domain concepts, boundaries, and long-lived abstractions.

Positive points:

- It maps well to business entities, workflows, and service boundaries.
- It helps organize large systems through interfaces, classes, and encapsulation.
- It can make collaboration easier when teams share clear domain models.

Functional programming is useful when a system benefits from data transformation, immutability, and predictable behavior.

Positive points:

- It keeps logic easier to reason about by reducing hidden state and side effects.
- It works well for data-heavy systems, pipelines, and transformations.
- It encourages small, composable functions that are easier to test and reuse.
